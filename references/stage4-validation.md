## 实现与兼容

- `broll.py`：严格 SRT 解析、稳定字幕 ID、版本化输入、真实母版参数/哈希、按 cue 或毫秒选段、显式吸附、原母版位置与句中切口提示。
- 应用只接受空分镜，保存配置备份并支持写入异常回滚；未选区间保留原视频，所选镜头沿用已有动画对象。新字段为可选 project.broll 和 shot.broll_segment，没有新字段的旧项目继续可用。
- `build_broll_preview.py` 与 `assets/review-preview/`：复用现有 Canvas clip 引擎，以真实项目音频作时钟，支持拖动、播放、镜头导航、区域开关、意见记录及 JSON 下载；提供本机字节范围服务器。
- `deliver_broll.py`：复用整片渲染器的逐镜头缓存，导出无声干净 H.264 和带母版位置、帧数、字幕 ID 的 Markdown/JSON 对照表；保留完整工程。
- 项目快照携带新工具、UI、引擎及字体，无需安装阿江 Skill 或新增 Remotion/Node 依赖。没有引入十套主题，没有修改其他 Skill 或用户产品工程。

方法参考阿江 `ajiang-video-broll` 的 `51aca5391ffe6190e929e2e4af1c439c0d3c2676`；本批代码与界面独立实现，来源说明见 THIRD_PARTY_NOTICES.md。

选中两段包装：B01 为第 9–275 帧（266 帧），B02 为第 369–491 帧（122 帧），均使用左闭右开区间。其余三段保留母版位置，整条时间线保持 540 帧。

最终预览实际检查 45 个时刻，覆盖首尾、镜头边界及每半秒采样；本样片没有产生文字/区域告警。软件 API 报告的暂停声音定位最大误差约 0.000002 秒，播放抽样时画面与声音时钟相差约 0.033 秒。该结果只描述浏览器时钟与帧网格，不代表声卡输出、词级对齐或人耳同步精度。另用刻意遮挡/狭小字幕区的测试确认告警能触发，不能把“零告警”当成完整视觉验收。

已查看实际预览界面与三个成片代表帧：生成图卡片、可编辑标题说明、声音轨交付说明均可见，字幕在所看帧没有观察到截断。头像明确显示为占位圆。没有完整试听、全片逐帧或真人遮挡验收。

最终短样片为 18 秒、540 帧、H.264/AAC，包含原声音、句级字幕、母版画面和两段内置动画。帧数、分辨率、帧率、音轨时长、来源与完整解码通过；成片检查没有错误或黑场事件，静音检测列出五段低音量区间待听审。编码后约 -21.85 LUFS、-9.59 dBTP，是该测试混音的结果，不是统一平台标准。

## 实测发现与修正

1. 普通 Python 静态服务器下，Chromium 虽缓冲了 WAV，却把可定位范围报告为 0，拖动画面后声音停在原处。增加 HTTP Range 支持并等待 seeked；实际浏览器测试验证了真实定位，没有只检查滑块数字。
2. 隐藏叠加层最初让 DOM 尺寸变为零，影响字幕溢出提示。改为保留布局的隐藏方式，并验证关掉可见叠加后检查仍有效。
3. 初次生成的原片保留镜头缺少已有工程要求的描述字段。补齐并把原工程完整验证器加入回归，未放宽已有格式要求。
4. 一次并行渲染时发生引擎启动超时，未发布那次交付。后续串行重建及工程迁移均通过；最终交付复用现有整片镜头缓存，减少重复启动和重复渲染。没有据此宣称通过高并发压力测试。
