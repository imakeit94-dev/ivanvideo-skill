日期：2026-10-17。本轮只制作工程测试样片，没有制作完整商业宣传片。

- FFmpeg 合成内置动画、静态配图及视频素材，支持硬切、淡化和可编辑字幕侧车。
- 已提供音频的 voice/music/sfx 分轨、采样点定位、区间 ducking、可选双遍响度标准化。
- 保存素材及配置哈希；拒绝过期混音；最终发布前核对帧数、规格、全片解码、音轨时长及编码后峰值。
- 中文口播编辑、事实保护和真实产品证据流程。
- 项目内工具/引擎/字体快照，保持与全局 Skill 的安装目录分离。

## 自动回归

运行 `python3 -m unittest discover -s tests -v`，14 个测试通过：

- 原初始化入口的横屏、竖屏与方形默认值；原项目缺少新字段时仍能校验。
- 原有 animation 字段的代表性 t2_keynote_ui 输入。
- 14 个非整帧间隔镜头的相邻帧边界及总帧数，没有累积取整漂移。
- 合法重叠；拒绝未标明重叠、空隙、不支持转场及媒体/动画双重主画面。
- 拒绝缺素材、非有限时间参数、奇数 H.264 尺寸和非整数音频采样率。
- 字幕区间及重复 ID 校验；素材变动会改变时间线指纹。
- 实测音频时长、实际混音与双遍 loudnorm、有效缓存复用和过期混音拒绝。
- 拒绝超出片长的音轨及负起点音效。
- 真实渲染“淡化→硬切”和“硬切→淡化”，检查准确帧数及镜头内部的实际颜色像素。

实测发现当前 FFmpeg 在 setpts 后未保留供 xfade 使用的帧率信息；将 CFR 建立放到时间戳重置之后修复，上述两组真实合成测试均通过。

## 整片样片

18 秒、960×540、30 fps、H.264 MP4，共 540 帧；三个镜头包含两段内置动画、一张根据真实工程配置制作的原创新图、一次 0.3 秒淡化和一次硬切。

音频为本机 macOS Tingting 草稿声音、原创合成垫乐及一个短动作音效；人声三个片段实测为约 2.555、3.849、3.487 秒，使用既定位置编排。字幕标记 draft，不宣称逐词对齐，也不代表本轮已经建立自动 TTS 工作流。

最终文件完整解码、帧数、尺寸、帧率、音轨存在及音视频时长检查通过。AAC 成片实测约 -20.02 LUFS、-8.35 dBTP；这些是该样片的测量值，不是通用交付标准。响度日志使用 input_* 读取实际文件测量。

已查看代表帧联系表：常用中文字幕正常显示；转场中间帧可见；配置图明确标为非运行中的产品界面。未进行全片逐帧视觉验收或完整听感验收。静音检测标出五段低于阈值的区间，包含首尾淡入淡出及句内停顿；仍需试听解释，不能自动判为声音通过。未检测到黑场事件。

## 其他工程验证

- 1920×1080 的视频素材裁切/填充、360×640 竖屏和 360×360 方形，各导出 1.2 秒、36 帧测试并通过解码与规格检查。
- 有效视频源不足镜头长度时，预检查即拒绝。
- 将样片工程复制到不同目录，使用工程内工具和引擎独立重渲。最终代码版本另删除一段动画缓存，验证能从移动后的项目源码重新生成该动画并组成整片。
- 显式指定过期混音时失败，未产生请求的输出文件。
- 参考分析入口拒绝不存在的文件且不创建输出目录；实际读取样片后取得元数据和六张代表帧。
- 官方 skill-creator 结构验证通过，Python 编译及本地引用检查通过；原 slug、个人安装位置和自动调用设置保留。没有另开全新 Codex 会话验证自动触发。

本轮使用 Python 3.9/3.12、FFmpeg/FFprobe 7.1.1、已有 Playwright/Chromium；不安装大型框架、不修改全局开发环境。样片、声音、证据表和测试工程保留在用户视频工作区，不进入公开 Skill 仓库。

## 未验证与边界

- 尚未接入通用 TTS 提供方、自动按句排时或强制词级对齐；本机 say 只用于测试素材。
- 未用真实第三方产品运行界面完成组件或功能验收；本轮验证的是证据流程及配置图来源。
- 未制作 Remotion 专用合成器、复杂多层转场或透明输出。
- 字幕遮挡、字形全集覆盖、复杂长文本、精确动作音效听感、所有平台安全区和长片性能仍需具体项目审核。
- 本轮没有重新渲染八种 grammar 的全部静帧；此前的覆盖范围保留于 integration-validation.md。本轮代表性动画与新增整片流程测试不替代所有内容/画幅组合的验收。

本地完整样片与详细运行报告位于相应视频项目的 outputs/、audio/mixes/ 和 references/；公共仓库仅保存实现、回归测试和本记录。
