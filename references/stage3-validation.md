## 自动回归

`uv run --offline --with playwright python -m unittest discover -s tests -v`：40 项通过，包含第一、二批原有 27 项和本批 13 项。

新增覆盖：

- 仅检查不写文件；参考图缺失仍可生成待准备请求，不产生虚假成品。
- 未知镜头、重复素材 ID、缺失视频时长会失败。
- 导入复制真实文件并保留旧清单条目；重复导入不覆盖。
- 修改素材字节、原请求或生成前参考图会被拒绝。
- 任务 ID/不存在的文件、改扩展名的静态图不算视频；AI 来源缺实际提供方/提示词会失败。
- FFmpeg 编码的 2 秒、30 帧视频实际导入，来源明确为 synthetic_test，不称为模型输出。
- 新素材证据绑定与无新字段的旧工程均可用，引用另一文件会失败。
- 中文标题仍在 HTML 中，输入转义；重复封面 ID 被拒绝。
- 实际浏览器输出三种比例 PNG，核对尺寸、文字布局、源图未改变与字体许可；已有输出目录拒绝覆盖。
- 极长标题布局失败时不发布半成品目录。

官方 skill-creator quick_validate、Python 编译、UI YAML 元数据及本地引用检查通过。slug、显示名称和自动调用策略保持不变；当前会话的 Skill 目录可定位其安装文件。没有另开全新 Codex 会话测试热更新后的自动触发。

## AI 视频与剩余边界

当前没有检测到 Dreamina/即梦 CLI，也没有暴露实际可调用的 AI 视频生成工具。因此视频分支只验证规划/提示词、真实编码视频导入与失败输入检查；**未验证 AI 视频提供方的生成、异步任务、下载、计费、模型一致性或音轨质量**。示例 V01 仍为 planned，未把静图、任务 ID 或测试夹具标为已生成视频。

生成伪影、技术事实、人物/商标与素材条款、精确字形、视觉层级、缩略图效果、完整听感仍需人工审阅。自带字体之外的字体授权由项目留档；封面不自动判断平台当前上传规则。没有声称覆盖所有视频编码或所有操作系统。

具体生成原图、提示词、配音、三种封面、工程迁移副本及详细机器报告保存在用户本地视频工程；公开仓库只保存工作流、工具和合成测试。
