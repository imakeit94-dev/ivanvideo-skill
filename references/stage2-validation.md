# 第二批融合验证记录

日期：2026-10-17。目标为中文 TTS、配音实测时长驱动排时、句级字幕同步和真实软件画面采集。用户选择先用本机工具验证。

## 已实现

- `narrate.py`：调用已安装的 macOS say 声音或导入提供的音频；统一为 48 kHz 单声道 PCM，按采样数测量，保存逐句缓存和版本清单。
- `schedule_narration.py`：从现有分镜及实测声音生成候选镜头、音轨、字幕和时间表；显式应用时保存修改前副本，异常时回滚；尊重固定时长或明确的 resize 选择。
- `capture_web.py`：独立浏览器上下文中的实际页面采集、明确操作、文本/URL 断言、PNG、原始 WebM、H.264 和来源记录。
- 编译器新增生成口播与捕获来源校验，支持 measured/sentence_clip 时间；导出 ASS 和 SRT，并把新工具保存在项目快照中。

入口与格式见 narration-production.md 和 software-capture.md。没有引入新的大型框架或云端 TTS SDK。

## 回归测试

`python3 -m unittest discover -s tests -v`：27 项通过，包含第一批 14 项原有回归和第二批 13 项测试。

新增覆盖：

- 实际中文 Tingting 合成及缓存复用；提供音频的实测采样数和单句变化只重建对应缓存。
- 候选计划不改原工程；应用后保留媒体/文本、生成备份；重复应用不改内容。
- 人声片长与字幕区间一致；固定时长不足时报错，明确 resize 后可调整；保留转场并校验句子顺序。
- 口播文案、分镜旁白、原音频或生成轨时刻改变时拒绝旧时间；未知镜头 ID 会失败。
- 已审核文本不一致、重复句子 ID、损坏的声音缓存会失败。
- 注入验证失败后，配置、分镜和新增时间文件正确回滚。
- 捕获绑定核对规范/媒体哈希；不允许步骤占用保留的录屏资产 ID。
- 新工程尚无 src/clips 目录时，带句界 anchor 的动画仍能校验与编译。

实测修复两处路径问题：新 API 规范化 macOS 临时路径别名；动画时间文件在创建 clip 目录前先 resolve，再做哈希读取。没有削弱工程内输出路径限制。

## 实际软件采集

使用本机 Python 标准库的 HTTP 文件浏览服务，服务目录只包含测试工程生成的 project.json。Chromium 实际打开目录、点击文件链接，并断言存在 project.json、目标 URL 和 fps=30 的内容。

成功保存两张实际 PNG、约 5.6 秒录屏、操作断言和捕获报告；页面异常为零。另用实际浏览器执行一个预期失败的文本断言，脚本返回失败且没有发布捕获目录。更新后的截图模式也实际运行通过。

这是本机工具的真实网页采集，未重画 UI。测试文件是本项目自己的数据快照；没有把它声称为用户产品运行结果。只验证所列操作与观察，不将其推广成所有产品功能已验收。

## 配音与样片

三句中文由本机已有 Tingting 声音生成，实测约 3.089、3.276、3.769 秒。原样再次生成时三句均命中缓存。

完整样片为 17 秒、960×540、30 fps、510 帧、H.264/AAC：一段内置动画、一段真实浏览器录屏、一张实际捕获帧，包含淡化、句级字幕、句界动画 anchor 及声音。按配置保留读图停留，没有为缩短样片而加速声音。

帧数、规格、完整解码、音轨时长、混音来源及字幕侧车输出通过。编码文件实测约 -20.02 LUFS、-7.43 dBTP；为本样片结果，不是通用平台标准。机器静音检测提供五段低音量区间线索；没有黑场事件。

已查看实际捕获的 JSON 页面及六张代表帧联系表，能够看到目录到文件内容的变化和字幕。尚未进行全片逐帧视觉验收或完整试听，不能据此保证发音、听感和全部遮挡问题都已通过。

## 环境及剩余边界

使用已有 Python 3.9/3.12、FFmpeg/FFprobe 7.1.1、Playwright/Chromium 和 macOS 声音；未安装大型框架或声音包，未调用收费 API。官方 skill-creator 结构验证、Python 编译、UI 元数据与引用检查通过；slug 和自动调用策略保持不变。没有另开全新 Codex 会话做自动触发测试。

- 目前自动合成提供方为 macOS 系统声音；其他服务以音频导入，没有声称接入某家云 TTS。
- measured 指真实声音片段区间，包括内部停顿；没有词级、音素级强制对齐或口型能力。
- 网页采集不是通用原生桌面录屏；没有测试登录态、所有复杂业务组件或用户尚未提供的产品。
- 未验证跨操作系统合成同一系统声音；保留 PCM 后的剪辑/导出不要求系统声音提供方仍可用。
- 时间重排后其他音乐/音效保留原时刻，录屏保留实际长度；要重新检查它们，不会静默拉伸、循环或裁短。
- 长片压力、所有字形与安全区组合、完整听感及用户具体产品真实性仍需对应工程验收。

具体样片、声音、源捕获、证据表、修订前后副本和详细机器报告保存在用户视频工程中，不进入公开 Skill 仓库。
