# 内置动画整合验证

2026-10-17，在独立临时视频工程中验证。测试素材为原创示意文字、简单测试图与合成音调；没有使用商业产品素材或真人配音。

## 已执行

- 官方 `skill-creator/scripts/quick_validate.py` 结构验证通过；UI 元数据、引用链接、八种 grammar 模块与许可文件检查通过。
- 初始化 16:9、9:16、1:1 均产生对应宽高；自定义尺寸支持推导画幅；明确冲突的画幅/尺寸在创建文件前拒绝。
- 八种语法各渲染两张不同时间的静帧，全部成功，帧间画面确有变化。包含横屏、竖屏和方形示例。代表帧联系表已实际检查。
- `t2_keynote_ui` 从分镜生成 clip，旁白草稿中的 1.2 秒 anchor 正确换算；渲染 960×540、30 fps、120 帧 MP4，并加入 1 秒合成音调，音轨补齐至 4 秒。片段 QA 确定性通过，异常跳变 0、框景告警 0。
- `y5_kinetic_type` 使用复制到工程的工具独立渲染 360×640、30 fps、90 帧 MP4。QA 确定性通过、框景告警 0；三个快速变化点已取前后帧检查，为设计中的色带转场。
- 修改后的通用 `y4_storytime` 角色渲染 640×360、30 fps、90 帧 MP4；QA 确定性通过、框景告警 0。一个快速变化点取前后帧检查为反应镜头变化。去掉默认帽子和眼镜后的工程副本也能独立重渲 PNG。
- 视频解码、参数对比、音视频时长、黑场/静音检测与镜头边界取帧入口已运行。音调补齐导致的静音被标记为复核线索，没有被误称为配音验收通过。
- 未知 cue kind、超时 cue、缺图片、无旁白段的 anchor、非有限数值和不支持的左右安全区输入会提前拒绝。
- 工程保留自身的动画引擎、字体、clip JSON、渲染工具与参数记录；工程内运行时成功执行，不需要读取另一个 Skill 的安装路径。

## 实际运行环境

Python 3.12.12、Playwright 1.64.0、Chromium 156.0.8078.4、NumPy 2.5.4、Pillow 13.0.0、FFmpeg 7.1.1。使用已有 Chromium 和隔离 Python 依赖，没有改变全局开发环境。每次渲染另记录源码与 spec 的哈希和实际版本。

## 未验证或仍需项目验收

真实 TTS、语音识别/强制对齐 API、真人口型同步、Remotion 整片合成和平台上传均未在本轮运行。旁白 anchor 测试验证了时间映射，没有验证草稿时间与真实口语的准确度。

八种语法的静帧运行通过不等于所有内容与画幅组合都已经视觉验收。完整长片、复杂技术动画、透明输出、平台左右浮层安全区以及跨操作系统像素一致性，需要对应工程的实现和实测。没有声称进行了真实旁白的全片试听。

更新后的逻辑若影响上述行为，应按变化重新运行相关验证，并记录失败及修复证据，不把旧结论直接用于新版本。
